# Ejercicio Individual Módulo 4 – Tarjeta de Crédito 💳

Este proyecto es parte del curso BOTIC-SOFOF y representa una solución orientada a objetos para simular el funcionamiento de una **Tarjeta de Crédito**, incluyendo:

- Compras
- Pagos
- Cálculo de intereses
- Encadenamiento de métodos
- Métodos de clase
- BONUS: Seguimiento de todas las tarjetas creadas

## 📂 Estructura

- `tarjeta_credito.py`: Código principal con definición de clase y pruebas
- `README.md`: Este archivo con instrucciones y descripción del proyecto

## ▶️ Cómo ejecutar

```bash
python tarjeta_credito.py
```

Asegúrate de tener Python instalado.
